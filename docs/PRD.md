# 产品需求文档（PRD）

## 文档信息

**产品名称：** Crosshair Pro - 外置准心覆盖软件
**文档版本：** v1.0
**创建日期：** 2026-06-07
**状态：** 草稿

---

## 1. 产品概述

### 1.1 产品背景

在FPS（第一人称射击）游戏中，准心是玩家瞄准的核心工具。许多游戏内置准心无法满足玩家的个性化需求，不同游戏场景需要不同类型的准心配置。外置准心覆盖软件作为一种游戏辅助工具，能够在游戏画面上叠加自定义准心，帮助玩家获得更好的瞄准体验。

市场上现有的准心软件（如CrosshairX、CrossOver等）已经证明了该需求的真实性和市场价值。本产品旨在提供一款功能完善、性能优异、用户体验出色的准心覆盖软件。

### 1.2 产品定位

一款面向FPS游戏玩家的专业准心定制工具，提供丰富的准心样式、精细的参数调节、便捷的预设管理和优秀的游戏兼容性。

### 1.3 目标用户

**主要用户：** FPS游戏玩家
**用户画像：**
- 年龄：18-35岁
- 游戏类型：FPS竞技游戏（CS2、Valorant、Apex Legends、Overwatch等）
- 需求特征：追求精准瞄准、个性化配置、多游戏切换
- 技术水平：中等，熟悉游戏设置和快捷键操作

### 1.4 产品目标

- **业务目标：** 成为Windows平台最受欢迎的准心覆盖软件之一
- **用户目标：** 提供最佳的自定义准心体验，提升玩家游戏表现
- **技术目标：** 实现低延迟（<16ms）、低资源占用（CPU<1%、内存<50MB）、高兼容性

## 2. 用户场景

### 2.1 用户旅程地图

**场景1：CS2竞技玩家配置**
- **用户：** 小明，CS2竞技玩家
- **目标：** 配置一个适合竞技的小型十字准心
- **步骤：**
  1. 打开软件，看到欢迎向导
  2. 选择预设库中的"CS2 Pro"配置
  3. 通过滑块微调准心大小、间隙、厚度
  4. 实时预览确认效果
  5. 按快捷键保存配置
  6. 启动CS2，软件自动检测并加载配置
- **痛点：** 游戏内准心调节繁琐，无法跨游戏复用配置
- **解决方案：** 提供实时预览、预设保存、游戏自动检测功能

**场景2：多游戏玩家切换**
- **用户：** 张华，同时玩Valorant和Apex
- **目标：** 为不同游戏使用不同准心配置
- **步骤：**
  1. 创建Valorant专用预设（小型点状准心，绿色）
  2. 创建Apex专用预设（圆形准心，黄色）
  3. 设置游戏关联
  4. 启动任意游戏，软件自动切换对应配置
- **痛点：** 不同游戏准心需求不同，手动切换麻烦
- **解决方案：** 游戏进程检测与配置自动切换

**场景3：自定义图片准心**
- **用户：** 李明，追求个性化
- **目标：** 使用自己设计的准心图片
- **步骤：**
  1. 设计并导出PNG格式准心图片（透明背景）
  2. 在软件中选择"自定义图片"选项
  3. 上传PNG文件
  4. 调整缩放、旋转、添加描边效果
  5. 保存并使用
- **痛点：** 预设样式无法满足个性化需求
- **解决方案：** 支持自定义图片导入和效果增强

**场景4：快速开关需求**
- **用户：** 王强，需要临时隐藏准心
- **目标：** 某些场景（如驾驶载具）临时关闭准心
- **步骤：**
  1. 按下Ctrl+Shift+X快捷键
  2. 准心立即隐藏
  3. 再次按下快捷键恢复显示
- **痛点：** 切出游戏调整影响体验
- **解决方案：** 全局热键快速开关

## 3. 功能需求

### 3.1 核心功能（P0 - MVP必需）

#### 3.1.1 准心渲染引擎

**功能描述：**
实现透明置顶窗口覆盖技术，在屏幕上渲染可自定义的准心。

**用户价值：**
这是软件的核心基础，使准心能够显示在游戏画面之上。

**技术方案：**
- 创建无边框、透明、置顶窗口
- 设置 `WS_EX_LAYERED | WS_EX_TRANSPARENT` 属性
- 实现鼠标点击穿透
- 支持全屏独占和无边框窗口模式

**详细规则：**
- 窗口层级始终置于最顶层
- 支持透明度渲染
- 准心位置默认在屏幕正中心
- 渲染延迟 < 16ms（保证60FPS流畅性）

**验收标准：**
- [ ] 准心能够显示在桌面和游戏窗口上方
- [ ] 鼠标点击能够穿透准心窗口
- [ ] 支持全屏独占和无边框窗口模式
- [ ] CPU占用 < 1%，内存占用 < 50MB

#### 3.1.2 准心样式系统

**功能描述：**
提供多种预设准心样式，包括十字、点状、圆形等。

**用户价值：**
满足不同玩家的瞄准习惯和游戏需求。

**支持样式：**

| 样式 | 描述 | 参数 | 适用场景 |
|------|------|------|----------|
| 十字准心 | 四条线从中心向外延伸 | 长度、粗细、间隙 | 通用型，最常用 |
| 点状准心 | 单个小点位于中心 | 大小、形状 | 狙击、精准射击 |
| 圆形准心 | 空心或实心圆环 | 半径、粗细、填充 | 追踪移动目标 |
| T形准心 | 倒T字形 | 横竖线长度 | 头部瞄准 |

**详细规则：**
- 样式切换即时生效
- 参数调整实时预览
- 支持参数范围限制

**验收标准：**
- [ ] 支持至少3种基础准心样式
- [ ] 参数调整实时反映到预览
- [ ] 样式渲染清晰无锯齿

#### 3.1.3 参数调节系统

**功能描述：**
提供准心参数的精细调节功能。

**参数列表：**

| 参数 | 描述 | 范围 | 默认值 |
|------|------|------|--------|
| 大小(Size) | 准心整体尺寸 | 1-100 | 20 |
| 间隙(Gap) | 中心空白区域 | 0-50 | 4 |
| 厚度(Thickness) | 线条宽度 | 1-10 | 2 |
| 颜色(Color) | 准心颜色 | RGB | #00FF00 |
| 透明度(Opacity) | 不透明程度 | 0-100% | 100% |

**界面要求：**
- **页面布局：** 滑块 + 数值输入框组合
- **交互方式：** 拖拽滑块快速调整，输入框精确设置
- **视觉设计：** 现代扁平化设计，参数分组清晰

**验收标准：**
- [ ] 所有参数支持滑块和数值输入两种方式
- [ ] 参数调整实时预览
- [ ] 参数值在有效范围内自动约束

#### 3.1.4 颜色选择器

**功能描述：**
提供准心颜色的自定义选择功能。

**详细规则：**
- 支持RGB颜色选择器
- 提供常用颜色预设（青色、绿色、黄色、红色、白色等）
- 支持颜色历史记录

**验收标准：**
- [ ] 支持任意RGB颜色选择
- [ ] 提供至少10种预设颜色
- [ ] 最近使用的颜色显示在历史区域

#### 3.1.5 全局热键系统

**功能描述：**
实现全局快捷键，在游戏内也能响应。

**默认快捷键：**

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 显示/隐藏准心 | Ctrl+Shift+X | 快速开关 |
| 切换预设 | Ctrl+Shift+1-9 | 数字键对应槽位 |
| 重置位置 | Ctrl+Shift+R | 回到中心 |

**详细规则：**
- 热键全局响应，游戏前台时也能触发
- 支持自定义快捷键绑定
- 冲突检测和提示

**验收标准：**
- [ ] 默认快捷键在游戏内可正常响应
- [ ] 支持自定义修改快捷键
- [ ] 快捷键冲突时给出提示

#### 3.1.6 配置保存与加载

**功能描述：**
支持准心配置的保存和加载。

**数据要求：**
- **存储格式：** JSON文件
- **存储位置：** 用户AppData目录
- **存储内容：** 样式、参数、快捷键绑定

**验收标准：**
- [ ] 配置自动保存
- [ ] 软件启动自动加载上次配置
- [ ] 支持配置导入导出

```
游戏启动 → 检测进程 → 匹配配置 → 自动加载 → 准心显示
```

### 5.2 状态转换

| 当前状态 | 触发条件 | 目标状态 | 说明 |
|---------|---------|---------|------|
| 空闲 | 启动游戏 | 游戏模式 | 自动检测游戏进程 |

- **加载反馈：** 导入配置时显示进度条

## 6. 数据需求

### 6.1 数据模型

#### 实体1：准心配置（CrosshairConfig）

**字段定义：**

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | string | 是 | UUID | 配置唯一标识 |
| name | string | 是 | - | 配置名称 |
| style | string | 是 | cross | 准心样式 |
| size | number | 是 | 20 | 准心大小 |
| gap | number | 是 | 4 | 中心间隙 |
| thickness | number | 是 | 2 | 线条厚度 |
| color | string | 是 | #00FF00 | 准心颜色 |
| opacity | number | 是 | 100 | 透明度(0-100) |
| outline | object | 否 | null | 描边设置 |
| shadow | object | 否 | null | 阴影设置 |
| customImage | string | 否 | null | 自定义图片路径 |
| createdAt | datetime | 是 | now | 创建时间 |
| updatedAt | datetime | 是 | now | 更新时间 |

**数据验证：**
- size: 1-100
- gap: 0-50
